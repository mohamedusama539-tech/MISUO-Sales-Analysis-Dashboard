Misuo sales analysis dashboard
An interactive sales dashboard built in Microsoft Excel to analyze sales performance, identify top-selling products, evaluate regional performance, and provide business recommendations.


Project Overview:
This project analyzes sales data for MISUO Furniture.

The objective is to evaluate sales performance, identify the best and worst-selling products, analyze customer demand across governorates, and support business decisions through interactive dashboards and data-driven recommendations.
Business Problem:
The management team needs a clear understanding of sales performance to support strategic decision-making.

This project aims to answer the following business questions:

- Which products generate the highest and lowest sales?
- Which governorates contribute the most to total sales?
- How is sales performance distributed across product categories?
- What is the current shipping status?
- What actions can increase sales and improve business performance?
Dataset:
The dataset contains sales transactions for MISUO Furniture and includes information such as:

- Order Date
- Product Name
- Product Category
- Selling Price
- Governorate
- Payment Method
- Shipping Status
- Sales Platform

The dataset was cleaned and transformed before analysis.
Data Cleaning:
The following data preparation steps were performed:
- Standardized governorate names.
- Corrected inconsistent data formats.
- Handled missing and invalid values.
- Created calculated columns for analysis.
- Prepared the dataset for Pivot Tables and Dashboard creation.
Dashboard:
The dashboard provides an interactive overview of sales performance using KPIs, Pivot Charts, and Slicers.

It allows users to filter data by:

- Governorate
- Sales Platform
